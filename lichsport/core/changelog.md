## V0.2

### Engine
- Removed old tuning parts textures and models
- Modeled and textured the **Common LichSport Tuning Parts** (v2), now having many more tuning parts and being more modular, also now has Lichsport badging and Tileable Materials.
- Removed Anti-Lag lua code, will use vanilla antilag in the future.

### Wheels
 - Removed Arima Celestia mod wheels.
- Modeled & Textured & JBeamed the LichSport Alpha wheels, Features :
 - Sizes 17x8, 18x8, 18x9, 18x10, 19x9, 19x10, 20x9 and 20x11.
 - Colors : Black, Bronze, Gold, Gunmetal, Pearl Silver, Purple, Red, Silver, White and Yellow.
 - Lug Nuts : 4 types, Colors : Black. Blue, Gold, Green, Purple, Red and Silver.
 - Center Caps : None, LichSport Logo and Blank.

## V0.3

### Wheels
- Implemented Badge system, now contains a few Vanilla beamng brands, White or colored LCST logo and some extra stuff, designed so more can be added later.
- Implemented Lugnut system, now has 4 Types of lugnuts, with more colors and colorable capabilities.
- Optimized Wheel Textures/Materials.
- Added Colorable Wheels.

### Gauges
- Removed 120MM 12K RPM Tachometer
- Modeled and Texture 52MM and 120MM Aftermarket Gauges including digital 7 segment display.
- JBeamed gauges to allow the ability to use slot nodeMove and nodeRotate to place them.
- Created a system to allow custom gauge faces to be used, currently theres **RPM**, **Water Temp**, **Oil Temp**, **Oil Pressure**, **Boost Pressure** and **Fuel Level**.
- Created a custom lua to handle the "bouncy" effect of the needles as well as making the gauge warning lights work..
- Using Zeit's simple lua HTML texture code, modified to fit my needs, i created the 7 segment display, it can display **RPM**, **Water Temp**, **Oil Temp**, **Oil Pressure**, **Boost Pressure** and **Wheel Speed**.
- All the aftermarket gauges come in **Black** or **White** and uses **Imperial** or **Metric**, except the data in the 7 segment display, those are only Metric values. ***TODO : Add imperial digital values***
- Modeled 3 Gauge Holders for the Sunburst, 2 in the middle of the Dash, and A pillar Gauges. ***TODO : Properly Texture Gauge Holders***
- Created custom texture for Sunburst gauge cluster, comes in **Black** or **White** and uses **Imperial** or **Metric**.
- Modified the colors of the default screen on the Sunburst gauge cluster to be **Red** and **White** instead of **Green** and **Black**.

### Exhaust 
- Modeled some exhaust tips, there are many Types divided in 3 categories :
 - Material : **Chrome**, **Black Chrome**, **Heated Titanium** or **Carbon Fiber**
 - Design : **Type A** or **Type B**. (this changes the shape of the tip)
 - Type : **Single tip**, **Dual tip** or **Wide tip**.
